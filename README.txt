DISTRICT BAR ASSOCIATION WEBSITE — RESPONSIVE UPDATE

Files:
- index.html
- about.html
- services.html
- members.html
- contact.html
- login.html
- register.html
- style.css
- script.js

How to use:
1. Extract this ZIP file.
2. Keep all files together in the same folder.
3. Open index.html in your browser.

What changed:
- Added an accessible hamburger menu for tablet and mobile widths.
- The menu opens as a dropdown panel and closes after choosing a link,
  clicking outside, or pressing Escape.
- Desktop navigation remains horizontal.
- Added responsive layout refinements for small screens.
- Existing page text, sections, colors and overall design have been retained.

Note:
The original HTML pages linked to style.css. The supplied stylesheet was
named style(2).css, so this project includes it as style.css to make the
pages work together without changing every page's stylesheet reference.
